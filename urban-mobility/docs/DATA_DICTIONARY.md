# Data dictionary

The processed file `data/processed/hourly_demand_weather.parquet` contains one row per observed hour and pickup zone for January 2024. Counts are taxi pickups, not unique rides requested or passengers served. Weather readings come from one Central Park station and are shared by all zones at a given hour.

| Field | Type | Meaning |
|---|---|---|
| `hour` | datetime | Start of the hour in New York local time. |
| `zone_id` | integer | NYC TLC pickup taxi-zone identifier. |
| `pickup_count` | integer | Number of trips whose pickup occurred in this zone during this hour. |
| `Borough` | text | Borough label from the TLC taxi-zone lookup. |
| `zone_name` | text | Taxi-zone name from the TLC taxi-zone lookup. |
| `hour_of_day` | integer | Local hour from 0 (midnight) to 23. |
| `day_of_week` | integer | Local weekday: Monday=0 through Sunday=6. |
| `is_weekend` | integer (0/1) | 1 when the local date is Saturday or Sunday. |
| `is_us_federal_holiday` | integer (0/1) | 1 when the date is a US federal holiday. |
| `temperature_c` | decimal | Mean valid hourly temperature observation in degrees Celsius. |
| `precipitation_mm` | decimal | Largest valid precipitation amount reported for the hour, in millimeters. Missing means no valid station observation was joined. |

Forecast output fields such as `predicted_pickups` are generated by the API and model; they are not columns in this input dataset. Anomaly output fields are documented by `reports/anomaly_alerts.csv` and represent review candidates, not confirmed events.
